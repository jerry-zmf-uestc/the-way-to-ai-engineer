# 示例：控制流

## Goal

使用边界判断、分支、循环和 `continue` 表达清晰的控制流。

## Concepts

- `if`
- `for`
- 早返回
- `continue`

## Run and test

```bash
go -C labs run ./part1-golang/chapter03/control-flow
go -C labs test ./part1-golang/chapter03/control-flow -race -count=1
```

程序会输出分数标签以及不超过 10 的偶数和。
