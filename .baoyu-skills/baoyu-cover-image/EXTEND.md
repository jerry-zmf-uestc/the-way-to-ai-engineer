# Agent 每日一题封面约定

封面用于技术知识系列：白底或极浅暖白，深蓝与少量青绿；保留约一半留白，无水印、英文眉题、页脚注释或装饰性网格。视觉表达任务、行动与反馈，避免机器人、霓虹电路和密集流程节点。正文流程图继续复用已审核的 Archify 图，不用封面代替技术图。

输出遵循 docs/rules/interview-content-contract.md，候选图、提示词与预览放仓库外 INTERVIEW_WORKSPACE，不写入正式 public 素材目录。标题默认不烘焙进封面，交由公众号标题栏展示。预览确认与草稿保存分开授权。
